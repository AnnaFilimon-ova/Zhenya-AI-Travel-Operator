# ✈️ Travel agent Zhenya

## 📌 Description
Zhenya is your personal travel agent. It finds flights, help you plan your trips, and makes traveling easier.

## 🛬 How to use
- Open Zhenya's Telegram Bot 
- Type /start
- Set up your profile in the mini app and follow Zhenya's progress
- Send Zhenya a message with your travel request

## 🚀 Features
- Beautiful  and user-friendly interface
- Flight search
- Additional mini app features, such as light and dark themes, English and Russian language options, and the ability to choose the bot's gender
- Shopping cart and payment options
